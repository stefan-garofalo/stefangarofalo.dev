# Public writing style

Use the Harness wiki's later public-writing rules for this article:

- Lead with a usable claim and its consequence.
- Make each beat advance one causal or operational move.
- Ground concepts through observable behavior, mechanism, and proof.
- Prefer direct claims, concrete transitions, and short paragraphs.
- Use prose for causality; lists, tables, diagrams, and code only when their structure carries information.
- Remove throat-clearing, rhetorical recaps, and questions that merely restate the preceding paragraph.
- Avoid em dashes.
- Never use reversal templates such as `not X, but Y`, `the subject did X; the subject did not do Y`, or `when scope became X, the thing fell apart`.

A beat has enough signal when the reader can say what happened, why it matters, and which part of the model explains it.
